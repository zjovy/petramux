# Roost Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Roost, a macOS desktop app for running many Claude Code sessions side by side, with live status from hooks, worktrees, resume, and a `roost` CLI that agents can use.

**Architecture:** A single Tauri 2 binary. A Rust core owns one PTY per session (portable-pty), a JSON state file and a Unix socket. The UI (Vite + vanilla TS + xterm.js) renders the sidebar and terminals. The same binary acts as the `roost` CLI when it gets a subcommand. Status comes from per-session Claude Code hooks (`--settings hooks.json`) that call `roost hook <Event>`, which writes to the socket.

**Tech Stack:** Rust (Tauri 2, portable-pty 0.9, serde, uuid, libc), TypeScript (Vite, xterm.js 5), bun.

**Spec:** `docs/specs/2026-10-11-roost-design.md`, plus mockups in `docs/specs/mockups/` (look = option A).

## Global Constraints

- macOS only. Tauri 2. Bundle id `dev.roost.app`, `productName` "Roost", `mainBinaryName` "roost".
- App files live in `~/Library/Application Support/Roost/`: `state.json`, `roost.sock`, `hooks.json`.
- Claude Code 2.1.296 or later. Roost never edits `~/.claude/settings.json`, never deletes worktrees or transcripts, and runs no git commands except `git rev-parse` to detect a repo.
- `roost hook` always exits 0, prints nothing, and gives up after 500 ms.
- Dependency list is closed. Rust: `tauri`, `tauri-build`, `tauri-plugin-single-instance`, `tauri-plugin-notification`, `tauri-plugin-dialog`, `serde`, `serde_json`, `uuid`, `portable-pty`, `libc`; dev: `tempfile`. JS: `@tauri-apps/api`, `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-webgl`; dev: `@tauri-apps/cli`, `typescript`, `vite`.
- Dark theme only. Tokens: `bg #0f0f11`, `line #1e1e23`, `sel #1b1b20`, `text #d6d6dc`, `mute #6b6b76`, `amber #f5a524`, `blue #6ea8fe`, `green #4ade80`.
- Terminal font `"JetBrains Mono", "SF Mono", Menlo, monospace` at 12.5 px; scrollback 10,000 lines.
- Deviations from the spec, decided here: `createdAt` is unix milliseconds (no date crate); `engine.rs` (window-free orchestration, not named `core` so it can't shadow Rust's `core` crate) and `paths.rs` are added to the layout so the integration test can drive the engine without Tauri; the crate is lib + bin (`roost_lib` + `roost`) so tests can import it; the flow test is not `#[ignore]`d because it uses a fake `claude` and runs in seconds; ⌘O's directory match is tightened to the repo and its `.claude/worktrees/*` (Task 7); an `ask` command provides native confirm dialogs (Task 10).

## Review Focus

1. **A prompt that starts with `-`** (for example `-v flag is broken`) must reach Claude as the prompt, not be parsed as a flag. Test in Task 6.
2. **Roost started from inside a Claude Code terminal** (dev runs) inherits `CLAUDECODE=1`, and nested `claude` refuses to start. The child env must strip `CLAUDECODE` and `CLAUDE_CODE_ENTRYPOINT`. Test in Task 4.
3. **Multi-byte UTF-8 split across PTY reads** (emoji, box-drawing, `⏺`) must not turn into `�`. Test in Task 6.
4. **A hook for an unknown session id** (row closed while Claude was still exiting) must be answered `ok` and ignored, not crash or create a row. Test in Task 9.
5. **Noisy or slow login shells** (prompt themes printing to stdout) must not break env capture. Parse only after the marker, and fall back on timeout. Test in Task 4.

```rust
#[derive(Clone, Debug)]
pub struct Paths {
    pub dir: PathBuf,
}

impl Paths {
    pub fn new(dir: impl Into<PathBuf>) -> Self {
        Self { dir: dir.into() }
    }
    pub fn default_dir() -> PathBuf {
        PathBuf::from(std::env::var("HOME").unwrap_or_default())
            .join("Library/Application Support/Roost")
    }
    pub fn state(&self) -> PathBuf {
        self.dir.join("state.json")
    }
    pub fn sock(&self) -> PathBuf {
        self.dir.join("roost.sock")
    }
    pub fn hooks(&self) -> PathBuf {
        self.dir.join("hooks.json")
    }
}

/// Socket for CLI calls: `$ROOST_SOCK` inside a session, else the default.
pub fn sock_from_env() -> PathBuf {
    std::env::var_os("ROOST_SOCK")
        .map(PathBuf::from)
        .unwrap_or_else(|| Paths::new(Paths::default_dir()).sock())
```

```rust
/// Reads state; a missing file is empty, a corrupt one is moved to `state.json.bak`.
pub fn load(path: &Path) -> State {
    let Ok(text) = fs::read_to_string(path) else {
        return State::default();
    };
    match serde_json::from_str(&text) {
        Ok(state) => state,
        Err(_) => {
            let _ = fs::rename(path, path.with_extension("json.bak"));
            State::default()
        }
    }
}

/// Atomic write: temp file, then rename.
pub fn save(path: &Path, state: &State) -> io::Result<()> {
    if let Some(dir) = path.parent() {
        fs::create_dir_all(dir)?;
    }
    let tmp = path.with_extension("json.tmp");
    fs::write(&tmp, serde_json::to_vec_pretty(state)?)?;
    fs::rename(tmp, path)
}

/// First four words, lowercase `a-z0-9-`, at most 24 chars.
pub fn slug(prompt: &str) -> String {
    let joined = prompt
        .split_whitespace()
        .take(4)
        .map(|w| w.to_lowercase())
        .collect::<Vec<_>>()
        .join("-");
    let mut out = String::new();
    for c in joined.chars() {
        if c.is_ascii_alphanumeric() {
            out.push(c);
        } else if !out.is_empty() && !out.ends_with('-') {
            out.push('-');
        }
    }
    let mut out: String = out.chars().take(24).collect();
    while out.ends_with('-') {
        out.pop();
    }
    if out.is_empty() {
        "session".into()
    } else {
        out
    }
}

pub fn unique_name(base: &str, taken: &[&str]) -> String {
    if !taken.contains(&base) {
        return base.into();
    }
    (2..)
        .map(|n| format!("{base}-{n}"))
        .find(|c| !taken.contains(&c.as_str()))
        .unwrap()
}
```

```rust
/// Status implied by a Claude Code hook event. `None` = leave status alone.
pub fn status_for(event: &str, payload: &serde_json::Value) -> Option<Status> {
    match event {
        "SessionStart" | "Stop" => Some(Status::Idle),
        "UserPromptSubmit" | "PostToolUse" => Some(Status::Working),
        "Notification" => match payload.get("notification_type").and_then(|v| v.as_str()) {
            Some("idle_prompt") => None,
            _ => Some(Status::NeedsYou),
        },
        _ => None,
    }
}
```

```rust
/// Parses `env -0` output after MARKER; anything before it is shell startup noise.
pub fn parse_env(out: &[u8]) -> Option<Env> {
    let text = String::from_utf8_lossy(out);
    let (_, rest) = text.split_once(MARKER)?;
    Some(
        rest.split('\0')
            .filter_map(|kv| kv.split_once('='))
            .filter(|(k, _)| !k.is_empty())
            .map(|(k, v)| (k.to_string(), v.to_string()))
            .collect(),
    )
}

/// Runs a command, returns stdout, or None if it fails or outlives `timeout`.
pub fn run_with_timeout(prog: &str, args: &[&str], timeout: Duration) -> Option<Vec<u8>> {
    let mut child = Command::new(prog)
        .args(args)
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()
        .ok()?;
    let mut stdout = child.stdout.take()?;
    let (tx, rx) = mpsc::channel();
    thread::spawn(move || {
        let mut buf = Vec::new();
        let _ = stdout.read_to_end(&mut buf);
        let _ = tx.send(buf);
    });
    let start = Instant::now();
    loop {
        match child.try_wait() {
            Ok(Some(_)) => break,
            Ok(None) if start.elapsed() < timeout => thread::sleep(Duration::from_millis(20)),
            _ => {
                let _ = child.kill();
                let _ = child.wait();
                return None;
            }
        }
    }
    // A background job left holding stdout open must not hang us.
    rx.recv_timeout(Duration::from_secs(1)).ok()
}

/// The user's login-shell env (apps opened from Finder don't get it), with a fallback.
pub fn capture_login_env() -> Env {
    let shell = std::env::var("SHELL").unwrap_or_else(|_| "/bin/zsh".into());
    let script = format!("printf {MARKER}; env -0");
    run_with_timeout(&shell, &["-lic", &script], Duration::from_secs(5))
```

```rust
/// Binds the socket (replacing any stale file) and serves each connection on a thread.
pub fn serve(path: &Path, handler: Handler) -> io::Result<()> {
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir)?;
    }
    let _ = std::fs::remove_file(path);
    let listener = UnixListener::bind(path)?;
    thread::spawn(move || {
        for conn in listener.incoming().flatten() {
            let handler = handler.clone();
            thread::spawn(move || {
                let _ = handle_conn(conn, handler);
            });
        }
    });
    Ok(())
}

fn handle_conn(conn: UnixStream, handler: Handler) -> io::Result<()> {
    let mut out = conn.try_clone()?;
    for line in BufReader::new(conn).lines() {
        let line = line?;
        if line.trim().is_empty() {
            continue;
        }
        let resp = match serde_json::from_str::<Request>(&line) {
            Ok(req) => handler(req),
            Err(e) => Response::err(format!("bad request: {e}")),
        };
        serde_json::to_writer(&mut out, &resp)?;
        out.write_all(b"\n")?;
    }
    Ok(())
}

/// One request, one response; `timeout` bounds both the write and the read.
pub fn call(path: &Path, req: &Request, timeout: Duration) -> io::Result<Response> {
    let mut conn = UnixStream::connect(path)?;
    conn.set_read_timeout(Some(timeout))?;
    conn.set_write_timeout(Some(timeout))?;
    let mut line = serde_json::to_vec(req)?;
    line.push(b'\n');
    conn.write_all(&line)?;
    let mut resp = String::new();
    BufReader::new(conn).read_line(&mut resp)?;
    Ok(serde_json::from_str(&resp)?)
}
```

```rust
    if let Launch::New { prompt, worktree } = launch {

            a.extend(["-w".into(), name.into()]);
        }
        if !prompt.trim().is_empty() {

impl Utf8Carry {
    /// Decodes what it can; holds back an incomplete trailing sequence for the next read.
    pub fn push(&mut self, bytes: &[u8]) -> String {
        self.tail.extend_from_slice(bytes);
        let cut = incomplete_tail_start(&self.tail);
        let rest = self.tail.split_off(cut);
        let text = String::from_utf8_lossy(&self.tail).into_owned();
        self.tail = rest;
        text
    }
}

/// Index where a trailing, not-yet-complete UTF-8 sequence starts (or len if none).
fn incomplete_tail_start(buf: &[u8]) -> usize {
    for i in (buf.len().saturating_sub(3)..buf.len()).rev() {
        let b = buf[i];
        if b & 0xC0 == 0x80 {
            continue; // continuation byte, keep looking for the lead byte
        }
        let need = match b {
            0xF0..=0xFF => 4,
            0xE0..=0xEF => 3,
            0xC0..=0xDF => 2,
            _ => 1,
        };
        return if buf.len() - i < need { i } else { buf.len() };
    }
    buf.len()
}

fn io_err(e: impl std::fmt::Display) -> io::Error {
    io::Error::new(io::ErrorKind::Other, e.to_string())
}

impl PtyManager {
    pub fn spawn(
        &self,
        id: &str,
        s: Spawn,
        on_output: impl Fn(String) + Send + 'static,
        on_exit: impl FnOnce() + Send + 'static,
    ) -> io::Result<()> {
        let size = PtySize { rows: s.rows, cols: s.cols, pixel_width: 0, pixel_height: 0 };
        let pair = native_pty_system().openpty(size).map_err(io_err)?;
        let mut cmd = CommandBuilder::new(&s.program);
        cmd.args(&s.args);
        cmd.cwd(&s.cwd);
        cmd.env_clear();
        for (k, v) in &s.env {
            cmd.env(k, v);
        }
        let mut child = pair.slave.spawn_command(cmd).map_err(io_err)?;
        drop(pair.slave);
        let mut reader = pair.master.try_clone_reader().map_err(io_err)?;
        let writer = pair.master.take_writer().map_err(io_err)?;
        let gen = self.gen.fetch_add(1, Ordering::SeqCst);
        let pid = child.process_id();
        self.procs
            .lock()
            .unwrap()
            .insert(id.to_string(), Proc { gen, master: pair.master, writer, pid });

        let (tx, rx) = mpsc::channel::<Vec<u8>>();
        thread::spawn(move || {
            let mut buf = [0u8; 65536];
            loop {
                match reader.read(&mut buf) {
                    Ok(0) | Err(_) => break,
                    Ok(n) => {
                        if tx.send(buf[..n].to_vec()).is_err() {
                            break;
                        }
                    }
                }
            }
        });
        // Coalesce output into at most one message per 16 ms.
        thread::spawn(move || {
            let mut carry = Utf8Carry::default();
            while let Ok(mut batch) = rx.recv() {
                let deadline = Instant::now() + Duration::from_millis(16);
                while let Some(left) = deadline.checked_duration_since(Instant::now()) {
                    match rx.recv_timeout(left) {
                        Ok(more) => batch.extend(more),
                        Err(_) => break,
                    }
                }
                let text = carry.push(&batch);
                if !text.is_empty() {
                    on_output(text);
                }
            }
        });
        let procs = self.procs.clone();
        let id = id.to_string();
        thread::spawn(move || {
            let _ = child.wait();
            {
                let mut map = procs.lock().unwrap();
                if map.get(&id).map(|p| p.gen) == Some(gen) {
                    map.remove(&id);
                }
            }
            on_exit();
        });
        Ok(())
    }

    pub fn write(&self, id: &str, data: &[u8]) -> io::Result<()> {
        let mut map = self.procs.lock().unwrap();
        let p = map
            .get_mut(id)
            .ok_or_else(|| io::Error::new(io::ErrorKind::NotFound, "session not running"))?;
        p.writer.write_all(data)?;
        p.writer.flush()
    }

    pub fn resize(&self, id: &str, cols: u16, rows: u16) {
        if let Some(p) = self.procs.lock().unwrap().get(id) {
            let _ = p.master.resize(PtySize { rows, cols, pixel_width: 0, pixel_height: 0 });
        }
    }

    pub fn is_running(&self, id: &str) -> bool {
        self.procs.lock().unwrap().contains_key(id)
    }

    /// SIGTERM to the process group; SIGKILL after 3 s if the same process is still there.
    pub fn kill(&self, id: &str) {
        let target = self.procs.lock().unwrap().get(id).and_then(|p| p.pid.map(|pid| (p.gen, pid)));
        let Some((gen, pid)) = target else { return };
        unsafe {
            libc::killpg(pid as i32, libc::SIGTERM);
        }
        let procs = self.procs.clone();
        let id = id.to_string();
        thread::spawn(move || {
            thread::sleep(Duration::from_secs(3));
            if procs.lock().unwrap().get(&id).map(|p| p.gen) == Some(gen) {
                unsafe {
                    libc::killpg(pid as i32, libc::SIGKILL);
                }
            }
        });
    }

    /// Used at quit: SIGTERM everything, give it 300 ms, then SIGKILL what's left.
    pub fn kill_all(&self) {
        let pids: Vec<u32> = self.procs.lock().unwrap().values().filter_map(|p| p.pid).collect();
        for pid in &pids {
            unsafe {
                libc::killpg(*pid as i32, libc::SIGTERM);
            }
        }
        thread::sleep(Duration::from_millis(300));
        for pid in &pids {
            unsafe {
                libc::killpg(*pid as i32, libc::SIGKILL);
            }
        }
    }
}
```

```rust
pub fn read_meta(path: &Path) -> Option<(String, String)> {
    let file = fs::File::open(path).ok()?;
    let (mut custom, mut ai, mut first, mut cwd) = (None, None, None, None);
    for line in BufReader::new(file).lines().map_while(Result::ok) {
        let Ok(v) = serde_json::from_str::<Value>(&line) else { continue };
        match v["type"].as_str() {
            Some("custom-title") => custom = v["customTitle"].as_str().map(String::from),
            Some("ai-title") => ai = v["aiTitle"].as_str().map(String::from),
            Some("user") if first.is_none() && v["isMeta"].as_bool() != Some(true) => {
                first = user_text(&v["message"]["content"]).filter(|t| !t.trim_start().starts_with('<'));
            }
            _ => {}
        }
        if cwd.is_none() {
            cwd = v["cwd"].as_str().map(String::from);
        }
    }
    let title = custom.or(ai).or(first)?;
    Some((one_line(&title, 80), cwd?))
}

fn user_text(content: &Value) -> Option<String> {
    match content {
        Value::String(s) => Some(s.clone()),
        Value::Array(parts) => parts
            .iter()
            .find(|p| p["type"] == "text")
            .and_then(|p| p["text"].as_str().map(String::from)),
        _ => None,
    }
}

fn one_line(s: &str, max: usize) -> String {
    let flat = s.split_whitespace().collect::<Vec<_>>().join(" ");
    if flat.chars().count() <= max {
        flat
    } else {
        flat.chars().take(max - 1).collect::<String>() + "…"
    }
}

pub fn list_past(projects: &Path, repo: &str, exclude: &HashSet<String>) -> Vec<Past> {
    let enc = encode_path(repo);
    let worktrees = format!("{enc}--claude-worktrees-");
    let mut files: Vec<(u64, PathBuf)> = vec![];
    for dir in fs::read_dir(projects).into_iter().flatten().flatten() {
        let name = dir.file_name().to_string_lossy().into_owned();
        if name != enc && !name.starts_with(&worktrees) {
            continue;
        }
        for f in fs::read_dir(dir.path()).into_iter().flatten().flatten() {
            let p = f.path();
            if p.extension().and_then(|e| e.to_str()) != Some("jsonl") {
                continue;
            }
            let id = p.file_stem().unwrap_or_default().to_string_lossy().into_owned();
            if exclude.contains(&id) {
                continue;
            }
            let ms = f
                .metadata()
                .and_then(|m| m.modified())
                .ok()
                .and_then(|t| t.duration_since(UNIX_EPOCH).ok())
                .map(|d| d.as_millis() as u64)
                .unwrap_or(0);
            files.push((ms, p));
        }
    }
    files.sort_by(|a, b| b.0.cmp(&a.0));
    // ponytail: reads whole transcripts, capped at the 50 newest; cache titles if ⌘O gets slow.
    files
        .into_iter()
        .take(50)
        .filter_map(|(ms, p)| {
            let (title, workdir) = read_meta(&p)?;
            let claude_id = p.file_stem()?.to_string_lossy().into_owned();
            Some(Past { claude_id, title, workdir, modified_ms: ms })
        })
        .collect()
}
```

```rust
pub fn parse(args: &[String]) -> Result<Cmd, String> {
    let cmd = args.first().map(String::as_str).unwrap_or("help");
    let rest: Vec<&str> = args.iter().skip(1).map(String::as_str).collect();
    match cmd {
        "new" => {
            let (mut prompt, mut worktree, mut cwd, mut name) = (None, None, None, None);
            let mut i = 0;
            while i < rest.len() {
                match rest[i] {
                    "--worktree" => worktree = Some(value(&rest, &mut i)?),
                    "--cwd" => cwd = Some(value(&rest, &mut i)?),
                    "--name" => name = Some(value(&rest, &mut i)?),
                    p if prompt.is_none() => prompt = Some(p.to_string()),
                    extra => return Err(format!("unexpected argument: {extra}")),
                }
                i += 1;
            }
            Ok(Cmd::New { prompt: prompt.unwrap_or_default(), worktree, cwd, name })
        }
        "ls" => Ok(Cmd::Ls { json: rest.contains(&"--json") }),
        "send" => match rest.as_slice() {
            [target, text] => Ok(Cmd::Send { target: target.to_string(), text: text.to_string() }),
            _ => Err("send takes <name|id> and \"<text>\"".into()),
        },
        "stop" => match rest.as_slice() {
            [target] => Ok(Cmd::Stop { target: target.to_string() }),
            _ => Err("stop takes <name|id>".into()),
        },
        "hook" => match rest.as_slice() {
            [event] => Ok(Cmd::Hook { event: event.to_string() }),
            _ => Err("hook takes <Event>".into()),
        },
        "help" | "--help" | "-h" => Ok(Cmd::Help),
        other => Err(format!("unknown command: {other}")),
    }
}

fn value(rest: &[&str], i: &mut usize) -> Result<String, String> {
    let flag = rest[*i];
    *i += 1;
    rest.get(*i).map(|s| s.to_string()).ok_or_else(|| format!("{flag} needs a value"))
}

/// Never fails and never prints: a hook must not block or alter Claude.
pub fn run_hook(sock: &Path, event: &str, stdin: impl Read, session: Option<String>) {
    let Some(session) = session else { return };
    let mut input = String::new();
    let _ = stdin.take(1 << 20).read_to_string(&mut input);
    let payload = serde_json::from_str(&input).unwrap_or(serde_json::Value::Null);
    let req = Request::Hook { session, event: event.into(), payload };
    let _ = call(sock, &req, Duration::from_millis(500));
}

pub fn run(args: &[String]) -> i32 {
    let cmd = match parse(args) {
        Ok(c) => c,
        Err(e) => {
            eprintln!("roost: {e}\n\n{USAGE}");
            return 2;
        }
    };
    let sock = sock_from_env();
    let me = std::env::var("ROOST_SESSION").ok();
    match cmd {
        Cmd::Hook { event } => {
            run_hook(&sock, &event, io::stdin(), me);
            0
        }
        Cmd::Help => {
            println!("{USAGE}");
            0
        }
        Cmd::New { prompt, worktree, cwd, name } => {
            let cwd = cwd.unwrap_or_else(|| ".".into());
            let cwd = std::path::absolute(&cwd).map(|p| p.display().to_string()).unwrap_or(cwd);
            let req = Request::New { prompt, cwd, worktree, name, parent: me };
            finish(call_launching(&sock, &req), |r| println!("{}", r.name.unwrap_or_default()))
        }
        Cmd::Ls { json } => finish(call(&sock, &Request::Ls, Duration::from_secs(2)), |r| {
            print_ls(&r.sessions.unwrap_or_default(), json)
        }),
        Cmd::Send { target, text } => {
            let req = Request::Send { target, text, from: me };
            finish(call(&sock, &req, Duration::from_secs(20)), |_| {})
        }
        Cmd::Stop { target } => finish(call(&sock, &Request::Stop { target }, Duration::from_secs(2)), |_| {}),
    }
}

fn finish(res: io::Result<Response>, ok: impl FnOnce(Response)) -> i32 {
    match res {
        Err(_) => {
            eprintln!("Roost isn't running");
            1
        }
        Ok(r) if !r.ok => {
            eprintln!("roost: {}", r.error.unwrap_or_default());
            1
        }
        Ok(r) => {
            ok(r);
            0
        }
    }
}

/// `new` starts the app if needed. Only retries when nothing is listening,
/// so a slow but delivered request is never sent twice.
fn call_launching(sock: &Path, req: &Request) -> io::Result<Response> {
    let t = Duration::from_secs(10);
    let not_listening = |e: &io::Error| matches!(e.kind(), io::ErrorKind::NotFound | io::ErrorKind::ConnectionRefused);
    match call(sock, req, t) {
        Err(e) if not_listening(&e) => {}
        other => return other,
    }
    let _ = std::process::Command::new("open").args(["-b", "dev.roost.app"]).status();
    let end = Instant::now() + Duration::from_secs(5);
    loop {
        thread::sleep(Duration::from_millis(200));
        match call(sock, req, t) {
            Err(e) if not_listening(&e) && Instant::now() < end => continue,
            other => return other,
        }
    }
}

fn print_ls(rows: &[LsRow], json: bool) {
    if json {
        println!("{}", serde_json::to_string_pretty(rows).unwrap_or_default());
        return;
    }
    for r in rows {
        let parent = r
            .parent
            .as_ref()
            .and_then(|p| rows.iter().find(|x| &x.id == p))
            .map(|p| format!("  ↳ {}", p.name))
            .unwrap_or_default();
        println!("{:<26} {:<10} {}{}", r.name, status_word(r.status), r.repo, parent);
    }
}

fn status_word(s: Status) -> &'static str {
    match s {
        Status::Starting => "starting",
        Status::Asleep => "asleep",
        Status::Working => "working",
        Status::NeedsYou => "needs-you",
        Status::Idle => "idle",
        Status::Exited => "exited",
    }
}
```

```rust
struct Live {
    status: Status,
    since: u64,
    spawned_at: Option<Instant>,
    resumed: bool,
    resume_failed: bool,
}

struct Inner {
    state: state::State,
    live: HashMap<String, Live>,
}

pub struct Core {
    inner: Mutex<Inner>,
    paths: Paths,
    env: Env,
    claude: Option<PathBuf>,
    ptys: PtyManager,
    sink: Arc<dyn Sink>,
    size: Mutex<(u16, u16)>,
    quitting: AtomicBool,
    me: Weak<Core>,
}

fn live(status: Status) -> Live {
    Live { status, since: state::now_ms(), spawned_at: None, resumed: false, resume_failed: false }
}

impl Core {
    pub fn new(paths: Paths, env: Env, claude: Option<PathBuf>, sink: Arc<dyn Sink>) -> Arc<Core> {
        let state = state::load(&paths.state());
        let live = state
            .sessions
            .iter()
            .map(|s| (s.id.clone(), live(if s.exited { Status::Exited } else { Status::Asleep })))
            .collect();
        Arc::new_cyclic(|me| Core {
            inner: Mutex::new(Inner { state, live }),
            paths,
            env,
            claude,
            ptys: PtyManager::default(),
            sink,
            size: Mutex::new((120, 36)),
            quitting: AtomicBool::new(false),
            me: me.clone(),
        })
    }

    pub fn handler(self: &Arc<Self>) -> Handler {
        let me = self.clone();
        Arc::new(move |req| me.handle(req))
    }

    pub fn claude_found(&self) -> bool {
        self.claude.is_some()
    }

    pub fn recent_repos(&self) -> Vec<String> {
        self.inner.lock().unwrap().state.recent_repos.clone()
    }

    pub fn views(&self) -> Vec<View> {
        let inner = self.inner.lock().unwrap();
        inner.state.sessions.iter().filter_map(|s| view(&inner, &s.id)).collect()
    }

    fn save(&self, inner: &Inner) {
        if let Err(e) = state::save(&self.paths.state(), &inner.state) {
            eprintln!("roost: could not save state: {e}");
        }
    }

    fn emit_all(&self) {
        self.sink.sessions_changed(self.views());
    }

    fn set_status(&self, id: &str, status: Status) {
        let (v, attention) = {
            let mut inner = self.inner.lock().unwrap();
            let Some(l) = inner.live.get_mut(id) else { return };
            if l.status == status || (l.status == Status::Exited && status != Status::Starting) {
                return;
            }
            let prev = l.status;
            l.status = status;
            l.since = state::now_ms();
            let attention = match (prev, status) {
                (_, Status::NeedsYou) => Some(Attention::NeedsYou),
                (Status::Working, Status::Idle) => Some(Attention::Done),
                _ => None,
            };
            (view(&inner, id), attention)
        };
        if let Some(v) = v {
            if let Some(a) = attention {
                self.sink.attention(&v, a);
            }
            self.sink.session_changed(v);
        }
    }

    /// Resolves a name or id to an id.
    fn resolve(&self, target: &str) -> Option<String> {
        let inner = self.inner.lock().unwrap();
        inner.state.sessions.iter().find(|s| s.id == target || s.name == target).map(|s| s.id.clone())
    }

    fn session(&self, id: &str) -> Option<Session> {
        self.inner.lock().unwrap().state.sessions.iter().find(|s| s.id == id).cloned()
    }

    fn status(&self, id: &str) -> Option<Status> {
        self.inner.lock().unwrap().live.get(id).map(|l| l.status)
    }

    pub fn new_session(&self, req: NewSession) -> Result<View, String> {
        if self.claude.is_none() {
            return Err("Claude Code not found. Install it, or set ROOST_CLAUDE_BIN.".into());
        }
        let session = {
            let mut inner = self.inner.lock().unwrap();
            let taken: Vec<&str> = inner.state.sessions.iter().map(|s| s.name.as_str()).collect();
            let base = state::slug(req.name.as_deref().unwrap_or(&req.prompt));
            let s = Session {
                id: uuid::Uuid::new_v4().to_string(),
                claude_id: uuid::Uuid::new_v4().to_string(),
                name: state::unique_name(&base, &taken),
                repo: req.repo.clone(),
                workdir: req.repo.clone(),
                worktree: req.worktree,
                parent: req.parent,
                created_at: state::now_ms(),
                exited: false,
            };
            inner.state.sessions.push(s.clone());
            inner.live.insert(s.id.clone(), live(Status::Starting));
            let recent = &mut inner.state.recent_repos;
            recent.retain(|r| r != &req.repo);
            recent.insert(0, req.repo.clone());
            recent.truncate(10);
            self.save(&inner);
            s
        };
        self.emit_all();
        self.spawn(&session, Launch::New { prompt: &req.prompt, worktree: req.worktree })?;
        self.view(&session.id).ok_or_else(|| "session vanished".into())
    }

    fn view(&self, id: &str) -> Option<View> {
        view(&self.inner.lock().unwrap(), id)
    }

    fn spawn(&self, s: &Session, launch: Launch) -> Result<(), String> {
        let claude = self.claude.clone().ok_or("Claude Code not found")?;
        let (cols, rows) = *self.size.lock().unwrap();
        let resumed = matches!(launch, Launch::Resume);
        let cwd = if resumed { &s.workdir } else { &s.repo };
        let spec = Spawn {
            program: claude,
            args: pty::claude_args(&s.claude_id, &s.name, &self.paths.hooks(), launch),
            cwd: PathBuf::from(cwd),
            env: shellenv::child_env(&self.env, &s.id, &self.paths.sock()),
            cols,
            rows,
        };
        if let Some(l) = self.inner.lock().unwrap().live.get_mut(&s.id) {
            l.spawned_at = Some(Instant::now());
            l.resumed = resumed;
            l.resume_failed = false;
        }
        self.set_status(&s.id, Status::Starting);
        let sink = self.sink.clone();
        let out_id = s.id.clone();
        let exit_id = s.id.clone();
        let me = self.me.clone();
        let result = self.ptys.spawn(
            &s.id,
            spec,
            move |text| sink.output(&out_id, text),
            move || {
                if let Some(core) = me.upgrade() {
                    core.on_exit(&exit_id);
                }
            },
        );
        if let Err(e) = result {
            self.on_exit(&s.id);
            return Err(format!("could not start claude: {e}"));
        }
        Ok(())
    }

    fn on_exit(&self, id: &str) {
        if self.quitting.load(Ordering::SeqCst) {
            return; // quitting: keep rows non-exited so they come back asleep
        }
        {
            let mut inner = self.inner.lock().unwrap();
            let Some(l) = inner.live.get_mut(id) else { return };
            l.resume_failed = l.resumed && l.spawned_at.is_some_and(|t| t.elapsed() < Duration::from_secs(3));
            if let Some(s) = inner.state.sessions.iter_mut().find(|s| s.id == id) {
                s.exited = true;
            }
            self.save(&inner);
        }
        self.set_status(id, Status::Exited);
    }

    pub fn select(&self, id: &str) -> Result<View, String> {
        if self.status(id) == Some(Status::Asleep) {
            let s = self.session(id).ok_or("no such session")?;
            self.spawn(&s, Launch::Resume)?;
        }
        self.view(id).ok_or_else(|| "no such session".into())
    }

    pub fn write(&self, id: &str, data: &[u8]) -> Result<(), String> {
        self.ptys.write(id, data).map_err(|e| e.to_string())
    }

    pub fn resize(&self, id: &str, cols: u16, rows: u16) {
        *self.size.lock().unwrap() = (cols, rows);
        self.ptys.resize(id, cols, rows);
    }

    pub fn rename(&self, id: &str, name: &str) -> Result<View, String> {
        {
            let mut inner = self.inner.lock().unwrap();
            let taken: Vec<String> =
                inner.state.sessions.iter().filter(|s| s.id != id).map(|s| s.name.clone()).collect();
            let taken: Vec<&str> = taken.iter().map(String::as_str).collect();
            let unique = state::unique_name(&state::slug(name), &taken);
            let s = inner.state.sessions.iter_mut().find(|s| s.id == id).ok_or("no such session")?;
            s.name = unique;
            self.save(&inner);
        }
        let v = self.view(id).ok_or("no such session")?;
        self.sink.session_changed(v.clone());
        Ok(v)
    }

    pub fn close(&self, id: &str) {
        self.ptys.kill(id);
        {
            let mut inner = self.inner.lock().unwrap();
            inner.state.sessions.retain(|s| s.id != id);
            inner.live.remove(id);
            self.save(&inner);
        }
        self.emit_all();
    }

    pub fn stop(&self, target: &str) -> Result<(), String> {
        let id = self.resolve(target).ok_or_else(|| format!("no session named {target}"))?;
        self.ptys.kill(&id);
        Ok(())
    }

    pub fn send(&self, target: &str, text: &str, from: Option<String>) -> Result<(), String> {
        let id = self.resolve(target).ok_or_else(|| format!("no session named {target}"))?;
        if self.status(&id) == Some(Status::Asleep) {
            self.select(&id)?;
            let end = Instant::now() + Duration::from_secs(15);
            while self.status(&id) == Some(Status::Starting) && Instant::now() < end {
                thread::sleep(Duration::from_millis(100));
            }
        }
        let prefix = from
            .and_then(|f| self.session(&f))
            .map(|s| format!("[from {}] ", s.name))
            .unwrap_or_default();
        let mut bytes = b"\x1b[200~".to_vec();
        bytes.extend(prefix.as_bytes());
        bytes.extend(text.as_bytes());
        bytes.extend(b"\x1b[201~");
        self.write(&id, &bytes)?;
        thread::sleep(Duration::from_millis(50));
        self.write(&id, b"\r")
    }

    pub fn start_fresh(&self, id: &str) -> Result<View, String> {
        let old = self.session(id).ok_or("no such session")?;
        let dir = if Path::new(&old.workdir).is_dir() { old.workdir.clone() } else { old.repo.clone() };
        self.close(id);
        self.new_session(NewSession { prompt: String::new(), repo: dir, worktree: false, name: Some(old.name), parent: old.parent })
    }

    pub fn list_past(&self, repo: &str) -> Vec<Past> {
        let open: HashSet<String> =
            self.inner.lock().unwrap().state.sessions.iter().map(|s| s.claude_id.clone()).collect();
        let home = self.env.get("HOME").cloned().unwrap_or_default();
        past::list_past(&Path::new(&home).join(".claude/projects"), repo, &open)
    }

    pub fn resume_past(&self, repo: &str, p: Past) -> Result<View, String> {
        let id = {
            let mut inner = self.inner.lock().unwrap();
            let taken: Vec<&str> = inner.state.sessions.iter().map(|s| s.name.as_str()).collect();
            let s = Session {
                id: uuid::Uuid::new_v4().to_string(),
                claude_id: p.claude_id,
                name: state::unique_name(&state::slug(&p.title), &taken),
                repo: repo.into(),
                workdir: p.workdir,
                worktree: false,
                parent: None,
                created_at: state::now_ms(),
                exited: false,
            };
            inner.live.insert(s.id.clone(), live(Status::Asleep));
            inner.state.sessions.push(s.clone());
            self.save(&inner);
            s.id
        };
        self.emit_all();
        self.select(&id)
    }

    pub fn shutdown(&self) {
        self.quitting.store(true, Ordering::SeqCst);
        self.ptys.kill_all();
    }

    pub fn handle(&self, req: Request) -> Response {
        let done = |r: Result<(), String>| r.map_or_else(Response::err, |_| Response::ok());
        match req {
            Request::New { prompt, cwd, worktree, name, parent } => {
                let req = NewSession { prompt, repo: cwd, worktree: worktree.is_some(), name: name.or(worktree), parent };
                match self.new_session(req) {
                    Ok(v) => Response { id: Some(v.id), name: Some(v.name), ..Response::ok() },
                    Err(e) => Response::err(e),
                }
            }
            Request::Ls => {
                let rows = self
                    .views()
                    .into_iter()
                    .map(|v| LsRow { id: v.id, name: v.name, status: v.status, repo: v.repo, parent: v.parent })
                    .collect();
                Response { sessions: Some(rows), ..Response::ok() }
            }
            Request::Send { target, text, from } => done(self.send(&target, &text, from)),
            Request::Stop { target } => done(self.stop(&target)),
            Request::Hook { session, event, payload } => {
                self.hook(&session, &event, &payload);
                Response::ok()
            }
        }
    }

    fn hook(&self, id: &str, event: &str, payload: &serde_json::Value) {
        {
            let mut inner = self.inner.lock().unwrap();
            let Some(s) = inner.state.sessions.iter_mut().find(|s| s.id == id) else { return };
            if event == "SessionStart" {
                if let Some(c) = payload["session_id"].as_str() {
                    s.claude_id = c.into();
                }
                if let Some(c) = payload["cwd"].as_str() {
                    s.workdir = c.into();
                }
                self.save(&inner);
            }
        }
        if let Some(st) = state::status_for(event, payload) {
            self.set_status(id, st);
        }
    }
}

fn view(inner: &Inner, id: &str) -> Option<View> {
    let s = inner.state.sessions.iter().find(|s| s.id == id)?;
    let l = inner.live.get(id)?;
    Some(View {
        id: s.id.clone(),
        name: s.name.clone(),
        repo: s.repo.clone(),
        workdir: s.workdir.clone(),
        worktree: s.worktree,
        parent: s.parent.clone(),
        status: l.status,
        since: l.since,
        created_at: s.created_at,
        resume_failed: l.resume_failed,
    })
}

/// The per-session Claude Code settings: one `roost hook <Event>` command per event.
pub fn hooks_json(exe: &Path) -> serde_json::Value {
    let quoted = format!("'{}'", exe.display().to_string().replace('\'', r"'\''"));
    let entry = |matcher: Option<&str>, event: &str| {
        let mut e = json!({"hooks": [{"type": "command", "command": format!("{quoted} hook {event}")}]});
        if let Some(m) = matcher {
            e["matcher"] = json!(m);
        }
        json!([e])
    };
    json!({"hooks": {
        "SessionStart": entry(None, "SessionStart"),
        "UserPromptSubmit": entry(None, "UserPromptSubmit"),
        "PostToolUse": entry(Some("*"), "PostToolUse"),
        "Notification": entry(Some("permission_prompt|elicitation_dialog"), "Notification"),
        "Stop": entry(None, "Stop"),
    }})
}

pub fn write_hooks(paths: &Paths, exe: &Path) -> io::Result<()> {
    std::fs::create_dir_all(&paths.dir)?;
    std::fs::write(paths.hooks(), serde_json::to_vec_pretty(&hooks_json(exe))?)
}
```

```rust
const PENDING_CAP: usize = 1 << 20;

struct UiSink {
    app: AppHandle,
    // Lock order: pending, then channels.
    pending: Mutex<HashMap<String, String>>,
    channels: Mutex<HashMap<String, Channel<String>>>,
    selected: Mutex<Option<String>>,
}

impl UiSink {
    fn attach(&self, id: String, ch: Channel<String>) {
        let mut pending = self.pending.lock().unwrap();
        if let Some(buf) = pending.remove(&id) {
            let _ = ch.send(buf);
        }
        self.channels.lock().unwrap().insert(id, ch);
    }

    fn detach(&self, id: &str) {
        self.pending.lock().unwrap().remove(id);
        self.channels.lock().unwrap().remove(id);
    }

    fn badge(&self, views: &[View]) {
        let n = views.iter().filter(|v| v.status == Status::NeedsYou).count() as i64;
        if let Some(w) = self.app.get_webview_window("main") {
            let _ = w.set_badge_count(if n > 0 { Some(n) } else { None });
        }
    }
}

impl Sink for UiSink {
    fn sessions_changed(&self, views: Vec<View>) {
        self.badge(&views);
        let _ = self.app.emit("sessions_changed", views);
    }

    fn session_changed(&self, view: View) {
        let _ = self.app.emit("session_changed", &view);
        if let Some(core) = self.app.try_state::<Arc<Core>>() {
            self.badge(&core.views());
        }
    }

    fn output(&self, id: &str, text: String) {
        let mut pending = self.pending.lock().unwrap();
        if let Some(ch) = self.channels.lock().unwrap().get(id) {
            if ch.send(text.clone()).is_ok() {
                return;
            }
        }
        let buf = pending.entry(id.to_string()).or_default();
        buf.push_str(&text);
        if buf.len() > PENDING_CAP {
            let from = buf.len() - PENDING_CAP;
            let cut = (from..buf.len()).find(|i| buf.is_char_boundary(*i)).unwrap_or(buf.len());
            buf.drain(..cut);
        }
    }

    fn attention(&self, view: &View, kind: Attention) {
        let focused = self
            .app
            .get_webview_window("main")
            .and_then(|w| w.is_focused().ok())
            .unwrap_or(false);
        let selected = self.selected.lock().unwrap().as_deref() == Some(view.id.as_str());
        if focused && selected {
            return;
        }
        let body = match kind {
            Attention::NeedsYou => format!("{} needs you", view.name),
            Attention::Done => format!("{} is done", view.name),
        };
        let _ = self.app.notification().builder().title("Roost").body(body).show();
    }
}

/// Quit, confirming first if any agent is mid-turn.
fn quit_guarded(app: &AppHandle) {
    let core = app.state::<Arc<Core>>().inner().clone();
    let working = core.views().iter().filter(|v| v.status == Status::Working).count();
    let handle = app.clone();
    let go = move || {
        core.shutdown();
        handle.exit(0);
    };
    if working == 0 {
        return go();
    }
    let msg = if working == 1 {
        "1 agent is working. Quit anyway?".to_string()
    } else {
        format!("{working} agents are working. Quit anyway?")
    };
    app.dialog()
        .message(msg)
        .kind(MessageDialogKind::Warning)
        .buttons(MessageDialogButtons::OkCancelCustom("Quit".into(), "Cancel".into()))
        .show(move |yes| {
            if yes {
                go()
            }
        });
}

/// Keeps `~/.local/bin/roost` pointing at this binary without clobbering anything else.
fn install_cli_link(exe: &Path) {
    let Some(home) = std::env::var_os("HOME") else { return };
    let link = Path::new(&home).join(".local/bin/roost");
    match std::fs::read_link(&link) {
        Ok(target) if target == exe => return,
        Ok(target) if target.file_name().is_some_and(|n| n == "roost") => {
            let _ = std::fs::remove_file(&link);
        }
        Ok(_) => {
            eprintln!("roost: ~/.local/bin/roost points somewhere else; leaving it");
            return;
        }
        Err(_) if link.symlink_metadata().is_ok() => {
            eprintln!("roost: ~/.local/bin/roost exists and isn't a symlink; leaving it");
            return;
        }
        Err(_) => {}
    }
    let _ = std::fs::create_dir_all(link.parent().unwrap());
    if let Err(e) = std::os::unix::fs::symlink(exe, &link) {
        eprintln!("roost: could not link the CLI: {e}");
    }
}

pub fn run_app() {
    tauri::Builder::default()
        .plugin(tauri_plugin_single_instance::init(|app, _args, _cwd| {
            if let Some(w) = app.get_webview_window("main") {
                let _ = w.unminimize();
                let _ = w.set_focus();
            }
        }))
        .plugin(tauri_plugin_notification::init())
        .plugin(tauri_plugin_dialog::init())
        .menu(menu)
        .on_menu_event(|app, e| {
            if e.id() == "quit" {
                quit_guarded(app);
            }
        })
        .setup(|app| {
            let handle = app.handle().clone();
            let paths = Paths::new(Paths::default_dir());
            let exe = std::env::current_exe()?;
            engine::write_hooks(&paths, &exe)?;
            install_cli_link(&exe);
            // ponytail: blocks startup while the login shell runs (5 s worst case); move to a thread if it's noticeable.
            let env = shellenv::capture_login_env();
            let claude = shellenv::find_claude(&env, std::env::var("ROOST_CLAUDE_BIN").ok());
            let sink = Arc::new(UiSink {
                app: handle,
                pending: Default::default(),
                channels: Default::default(),
                selected: Default::default(),
            });
            let core = Core::new(paths.clone(), env, claude, sink.clone());
            sock::serve(&paths.sock(), core.handler())?;
            app.manage(core);
            app.manage(sink);
            Ok(())
        })
        .on_window_event(|w, e| {
            if let WindowEvent::CloseRequested { api, .. } = e {
                api.prevent_close();
                quit_guarded(w.app_handle());
            }
        })
        .invoke_handler(tauri::generate_handler![
            boot, attach, select_session, new_session, write, resize, rename, close,
            start_fresh, list_past, resume_past, pick_folder, is_git_repo, ask
        ])
        .build(tauri::generate_context!())
        .expect("error while building Roost")
        .run(|app, event| {
            // `code: None` = the user or the OS asked to quit; `Some` = our own `exit(0)`.
            if let RunEvent::ExitRequested { api, code: None, .. } = event {
                api.prevent_exit();
                quit_guarded(app);
            }
        });
}
```

```ts
import type { View } from "./api";

export function ordered(views: View[]): { view: View; depth: number }[] {
  const ids = new Set(views.map((v) => v.id));
  const parentOf = (v: View) => (v.parent && ids.has(v.parent) ? v.parent : null);
  const kids = (id: string | null) =>
    views.filter((v) => parentOf(v) === id).sort((a, b) => a.createdAt - b.createdAt);
  const groups = new Map<string, View[]>();
  for (const root of kids(null)) {
    const g = groups.get(root.repo) ?? [];
    g.push(root);
    groups.set(root.repo, g);
  }
  const out: { view: View; depth: number }[] = [];
  const walk = (v: View, depth: number) => {
    out.push({ view: v, depth });
    for (const k of kids(v.id)) walk(k, depth + 1);
  };
  for (const roots of groups.values()) for (const r of roots) walk(r, 0);
  return out;
}

export function age(since: number): string {
  const s = Math.max(0, (Date.now() - since) / 1000);
  if (s < 60) return `${Math.floor(s)}s`;
  if (s < 3600) return `${Math.floor(s / 60)}m`;
  if (s < 86400) return `${Math.floor(s / 3600)}h`;
  return `${Math.floor(s / 86400)}d`;
}

const basename = (p: string) => p.split("/").filter(Boolean).pop() ?? p;

export interface Handlers {
  select(id: string): void;
  rename(id: string, name: string): void;
}

export function render(el: HTMLElement, views: View[], selected: string | null, on: Handlers) {
  el.replaceChildren();
  let lastRepo: string | null = null;
  for (const { view: v, depth } of ordered(views)) {
    if (depth === 0 && v.repo !== lastRepo) {
      lastRepo = v.repo;
      const g = document.createElement("div");
      g.className = "grp";
      g.textContent = basename(v.repo);
      g.title = v.repo;
      el.append(g);
    }
    const row = document.createElement("div");
    row.className = `row s-${v.status}${v.id === selected ? " on" : ""}`;
    row.dataset.id = v.id;
    row.style.paddingLeft = `${8 + depth * 14}px`;
    if (depth) row.append(span("tree", "└"));
    const name = span("name", v.name);
    const meta = span("meta", v.status === "needs_you" ? "" : age(v.since));
    if (v.status === "needs_you") meta.append(span("pill", "needs you"));
    row.append(span("dot", ""), name, meta);
    row.onclick = () => on.select(v.id);
    row.ondblclick = () => startRename(name, v, on.rename);
    el.append(row);
  }
}

function span(cls: string, text: string) {
  const s = document.createElement("span");
  s.className = cls;
  s.textContent = text;
  return s;
}

export function startRename(nameEl: HTMLElement, v: View, done: (id: string, name: string) => void) {
  const input = document.createElement("input");
  input.className = "rename";
  input.value = v.name;
  nameEl.replaceWith(input);
  input.focus();
  input.select();
  let finished = false;
  const finish = (save: boolean) => {
    if (finished) return;
    finished = true;
    const value = input.value.trim();
    if (save && value && value !== v.name) done(v.id, value);
    else input.replaceWith(nameEl);
  };
  input.onkeydown = (e) => {
    e.stopPropagation();
    if (e.key === "Enter") finish(true);
    if (e.key === "Escape") finish(false);
  };
  input.onblur = () => finish(true);
}
```

```ts
/** Mirrors Rust `state::slug` so the sheet can preview the name; Rust stays authoritative. */
export function slug(prompt: string): string {
  const joined = prompt.trim().split(/\s+/).slice(0, 4).map((w) => w.toLowerCase()).join("-");
  let out = "";
  for (const c of joined) {
    if (/[a-z0-9]/.test(c)) out += c;
    else if (out && !out.endsWith("-")) out += "-";
  }
  out = out.slice(0, 24).replace(/-+$/, "");
  return out || "session";
}

    if (await o.start(ta.value, repo, worktree)) close();
    else busy = false;
  };

  const pick = (path: string) => {
    void setRepo(path);
    repos.hidden = true;
    ta.focus();
  };

  const item = (label: string, detail: string, onClick: () => void) => {
    const b = document.createElement("button");
    const l = document.createElement("span");
    const d = document.createElement("span");
    l.textContent = label;
    d.textContent = detail;
    d.className = "a";
    b.append(l, d);
    b.onclick = onClick;
    return b;
  };

  const toggleRepos = () => {
    repos.hidden = !repos.hidden;
    if (repos.hidden) return ta.focus();
    repos.replaceChildren(
      ...o.recentRepos.map((r) => item(basename(r), r, () => pick(r))),
      item("Open folder…", "", async () => {
        const p = await api.pickFolder();
        if (p) pick(p);
        else ta.focus();
      }),
    );
    (repos.firstElementChild as HTMLElement | null)?.focus();
  };

  ta.oninput = () => {
    $(".nm").textContent = slug(ta.value);
  };
  overlay.addEventListener("keydown", (e) => {
    e.stopPropagation();
    if (e.key === "Escape") {
      e.preventDefault();
      if (repos.hidden) close();
      else toggleRepos();
    } else if (e.metaKey && e.key.toLowerCase() === "p") {
      e.preventDefault();
      toggleRepos();
    } else if (e.key === "Enter" && !e.shiftKey && e.target === ta) {
      e.preventDefault();
      void start(e.altKey);
    }
  });
  overlay.onmousedown = (e) => {
    if (e.target === overlay) close();
  };
  $(".go").onclick = () => void start(false);
  wt.onclick = () => void start(true);
  repoBtn.onclick = toggleRepos;
  void setRepo(repo);
  ta.focus();
}
```

```ts
import { api, type Past } from "./api";
import { age } from "./sidebar";

const basename = (p: string) => p.split("/").filter(Boolean).pop() ?? p;

function div(cls: string, text: string) {
  const d = document.createElement("div");
  d.className = cls;
  d.textContent = text;
  return d;
}

export interface PickerOptions {
  repo: string;
  pick(p: Past): Promise<boolean>;
  closed(): void;
}

export async function openPicker(o: PickerOptions) {
  const overlay = document.createElement("div");
  overlay.className = "overlay";
  const box = div("picker", "");
  const input = document.createElement("input");
  input.placeholder = `Resume a session in ${basename(o.repo)}…`;
  const listEl = div("list", "");
  listEl.append(div("none", "Loading…"));
  box.append(input, listEl);
  overlay.append(box);
  document.body.append(overlay);
  input.focus();

  let all: Past[] = [];
  let shown: Past[] = [];
  let at = 0;
  let busy = false;

  const close = () => {
    overlay.remove();
    o.closed();
  };
  const mark = () => {
    listEl.querySelectorAll(".item").forEach((el, i) => el.classList.toggle("on", i === at));
    listEl.children[at]?.scrollIntoView({ block: "nearest" });
  };
  const choose = async (p: Past) => {
    if (busy) return;
    busy = true;
    if (await o.pick(p)) close();
    else busy = false;
  };
  const render = () => {
    const q = input.value.trim().toLowerCase();
    shown = all.filter((p) => p.title.toLowerCase().includes(q));
    at = Math.min(at, Math.max(0, shown.length - 1));
    listEl.replaceChildren();
    if (!shown.length) {
      listEl.append(div("none", all.length ? "No matches." : "No past sessions for this repo."));
      return;
    }
    shown.forEach((p, i) => {
      const row = document.createElement("button");
      row.className = `item${i === at ? " on" : ""}`;
      row.append(div("t", p.title), div("a", age(p.modifiedMs)));
      row.onmouseenter = () => {
        at = i;
        mark();
      };
      row.onclick = () => void choose(p);
      listEl.append(row);
    });
  };

  input.oninput = () => {
    at = 0;
    render();
  };
  overlay.addEventListener("keydown", (e) => {
    e.stopPropagation();
    if (e.key === "Escape") close();
    else if (e.key === "ArrowDown") {
      e.preventDefault();
      at = Math.min(at + 1, shown.length - 1);
      mark();
    } else if (e.key === "ArrowUp") {
      e.preventDefault();
      at = Math.max(at - 1, 0);
      mark();
    } else if (e.key === "Enter" && shown[at]) {
      e.preventDefault();
      void choose(shown[at]);
    }
  });
  overlay.onmousedown = (e) => {
    if (e.target === overlay) close();
  };

  all = await api.listPast(o.repo).catch(() => []);
  render();
}
```
